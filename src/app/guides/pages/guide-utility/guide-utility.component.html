📄 Guide

Utility

Managing and inspecting uv's state, such as the cache, storage directories, or performing a self-update.

🚫

Cache management

Manage uv's cache to free up disk space or remove outdated entries.

Clean uv cache clean Remove cache entries
Prune uv cache prune Remove outdated cache entries
Info uv cache dir Show the uv cache directory path
📁

Directory inspection

View the directories where uv stores tools and Python versions.

Info uv tool dir Show the uv tool directory path
Info uv python dir Show the uv installed Python versions path
🔄

Self-update

Keep uv up to date with the latest features and bug fixes.

Update uv self update Update uv to the latest version
