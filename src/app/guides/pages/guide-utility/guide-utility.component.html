Utility

Managing and inspecting uv's state, such as the cache, storage directories, or performing a self-update.

Clean cache

Remove cache entries to free up disk space.

Example 
$ uv cache clean
Removed 125 cache entries (45.2 MB)
$ uv cache clean --older 30d
Removed 45 cache entries older than 30 days (12.3 MB)

Prune cache

Remove outdated cache entries that are no longer needed.

Example 
$ uv cache prune
Pruned 32 outdated cache entries (8.5 MB)
$ uv cache prune --dry-run
Would prune 32 entries (8.5 MB). Run without --dry-run to remove.

Cache directory

Show the path to uv's cache directory.

Example 
$ uv cache dir
/home/user/.cache/uv
$ du -sh $(uv cache dir)
1.2G

Tool directory

Show the path to uv's tool directory where installed tools are stored.

Example 
$ uv tool dir
/home/user/.local/share/uv/tools
$ ls $(uv tool dir)
black  ruff  mypy

Python directory

Show the path to uv's Python versions directory.

Example 
$ uv python dir
/home/user/.local/share/uv/python
$ ls $(uv python dir)
x86_64-unknown-linux-gnu

Self-update

Update uv to the latest version to get new features and bug fixes.

Example 
$ uv self update
Updating uv from 0.4.0 to 0.4.1
Downloading uv 0.4.1...
Installed uv 0.4.1
$ uv --version
uv 0.4.1

Summary

This guide covers the utility commands for uv. These commands help you manage uv's internal state, clean up disk space, and keep uv itself up to date.

What this guide helps you with

  • Clean up cache to free up disk space
  • Prune outdated cache entries automatically
  • Find the paths to uv's storage directories
  • Update uv to the latest version

How to use these commands

  • Use uv cache clean to remove all cache entries
  • Use uv cache clean --older 30d to remove old entries
  • Use uv cache prune to remove outdated entries automatically
  • Use uv self update to get the latest uv version
  • Use uv cache dir, uv tool dir, and uv python dir to find storage locations

Learn more

To explore more options, check out the official uv documentation:

  • uv self --help — Shows self-update options
