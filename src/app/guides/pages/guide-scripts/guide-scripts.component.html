Scripts

A Python script is a file intended for standalone execution, e.g., with python script.py Using uv to execute scripts ensures that script dependencies are managed without manually managing environments

Run scripts

uv run: Run a script

Run with dependencies

When your script requires other packages, uv prefers to create these environments on demand rather than using a virtual environment. This requires explicitly declaring the dependencies needed by the script

uv run --with fastapi example.py: Run a script with FastAPI dependencies

Declaring script dependencies

The inline metadata format allows the dependencies for a script to be declared in the script itself 

# /// script
# dependencies = [
#   "requests",
#   "rich",
# ]
# ///

import requests
from rich.pretty import pprint

resp = requests.get("https://peps.python.org/api/peps.json")
data = resp.json()
pprint([(k, v["title"]) for k, v in data.items()][:10])
  • uv add --script: Add a dependency to a script
  • uv remove --script: Remove a dependency from a script
