Scripts

A Python script is a file intended for standalone execution, e.g., with python script.py. Using uv to execute scripts ensures that script dependencies are managed without manually managing environments.

Run a script

Execute a Python script with uv. Dependencies are automatically managed in a temporary environment.

Example 
$ uv run script.py
Hello, World!
$ uv run --with fastapi script.py
Starting FastAPI server...
INFO: Uvicorn running on http://127.0.0.1:8000

Run with dependencies

Run a script with additional packages installed in a temporary environment.

Example 
$ uv run --with requests script.py
Fetching data from API...
Status: 200 OK
$ uv run --with pandas --with matplotlib analysis.py
Generating chart...
Chart saved to output.png

Add script dependency

Add a dependency to a script that uses inline metadata. Updates the script's dependency declarations.

Example 
$ uv add --script requests script.py
Updated script.py with dependency: requests
$ uv add --script rich --script script.py
Updated script.py with dependency: rich

Remove script dependency

Remove a dependency from a script that uses inline metadata.

Example 
$ uv remove --script requests script.py
Removed dependency: requests from script.py
$ uv remove --script rich --script script.py
Removed dependency: rich from script.py

Summary

This guide covers the scripts interface for uv. Scripts are Python files intended for standalone execution, and uv manages their dependencies automatically without requiring a full project setup.

What this guide helps you with

  • Run Python scripts with automatic dependency management
  • Run scripts with temporary dependencies without modifying the script
  • Add and remove dependencies directly in the script using inline metadata
  • Keep scripts self-contained and portable

How to use these commands

  • Use uv run script.py to execute a script
  • Use uv run --with package script.py for temporary dependencies
  • Add # /// script metadata to your script for persistent dependencies
  • Use uv add --script package script.py to add dependencies to the script
