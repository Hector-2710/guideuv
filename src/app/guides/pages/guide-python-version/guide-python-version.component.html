📄 Guide

Python version

If Python is already installed on your system, uv will detect and use it without configuration. However, uv can also install and manage Python versions. uv automatically installs missing Python versions as needed — you don't need to install Python to get started.

Install Python

Install Python versions managed by uv. You don't need Python installed beforehand — uv handles everything.

$ uv python install
Example 
$ uv python install
Installed Python 3.13.1 in 4.2s
$ uv python install 3.12
Installed Python 3.12.8 in 3.8s

List Python versions

View available Python versions installed by uv and those available for installation.

$ uv python list
Example 
$ uv python list
Installed Python versions:
  3.13.1
  3.12.8
  3.11.9

Available Python versions:
  3.14.0a1
  3.14.0a2
  3.13.1
  3.12.8
  3.11.9
  3.10.15

Find Python version

Find an installed Python version matching a specific requirement.

$ uv python find
Example 
$ uv python find 3.12
Found Python 3.12.8 at /home/user/.local/share/uv/python/x86_64-unknown-linux-gnu/cpython-3.12.8-linux-x86_64-gnu
$ uv python find 3.11
Found Python 3.11.9 at /home/user/.local/share/uv/python/x86_64-unknown-linux-gnu/cpython-3.11.9-linux-x86_64-gnu

Uninstall Python version

Uninstall a Python version that was installed by uv.

$ uv python uninstall
Example 
$ uv python uninstall 3.11.9
Uninstalled Python 3.11.9
$ uv python list
Installed Python versions:
  3.13.1
  3.12.8
