📄 Guide

Python version

If Python is already installed on your system, uv will detect and use it without configuration. However, uv can also install and manage Python versions. uv automatically installs missing Python versions as needed — you don't need to install Python to get started.

🔍

Install Python

Install Python versions managed by uv. You don't need Python installed beforehand — uv handles everything.

Install uv python install Install the latest Python version
Install uv python install 3.12 Install a specific Python version
⚙

Manage versions

View, find, and uninstall Python versions installed by uv.

List uv python list View available Python versions
Find uv python find Find an installed Python version
Remove uv python uninstall Uninstall a Python version
