📄 Guide

Introduction

uv provides essential features for Python development, from installing Python and hacking on simple scripts to working on large projects that support multiple Python versions and platforms.

📚

Overview

uv's interface can be broken down into sections, which are usable independently or together. Each section handles a specific aspect of Python development:

⚙

Python Version Management

Install and manage multiple Python versions

📦

Package Management

Install, update, and remove packages

📁

Project Management

Create and work with Python projects

💻

Tools

Run and install CLI tools

📅

Scripts

Execute standalone Python scripts

💰

Publishing

Build and publish packages
