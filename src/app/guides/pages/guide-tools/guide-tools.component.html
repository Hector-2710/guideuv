Tools

Running and installing tools published to Python package indexes, e.g., ruff or black.

Run tool on demand

Use uvx to run a tool in a temporary environment without installing it. Perfect for one-off commands.

$ uvx
Example 
$ uvx ruff check .
Checking files...
All files passed
$ uvx --from httpie http https://example.com
HTTP/1.1 200 OK
Content-Type: text/html...
▶ Run uvx Run tool without installing

Run installed tool

Run a tool that has been installed with uv tool install.

$ uv tool run
Example 
$ uv tool run ruff check .
Checking files...
All files passed
$ uv tool run black format .
reformatted 3 files
▶ Run uv tool run Run installed tool

Install tool

Install a tool user-wide for persistent access across your system.

$ uv tool install
Example 
$ uv tool install ruff
Installed tool: ruff
$ uv tool install black
Installed tool: black
📦 Install uv tool install Install tool user-wide

Uninstall tool

Uninstall a tool that was installed with uv tool install.

$ uv tool uninstall
Example 
$ uv tool uninstall ruff
Uninstalled tool: ruff
$ uv tool list
Installed tools:
  black
🗑 Remove uv tool uninstall Uninstall installed tool

List tools

List all tools installed user-wide.

$ uv tool list
Example 
$ uv tool list
Installed tools:
  black [23.12.0]
    - black
  ruff [0.1.6]
    - ruff
    - ruff-format
📋 List uv tool list List installed tools

Update shell

Update the shell to include tool executables in your PATH. Run this after installing tools.

$ uv tool update-shell
Example 
$ uv tool update-shell
Updated PATH in /home/user/.bashrc
Restart your shell or run: source /home/user/.bashrc
$ source ~/.bashrc && which ruff
/home/user/.local/bin/ruff
💻 Setup uv tool update-shell Update shell PATH

Summary

This guide covers the tools interface for uv. You can run tools on-demand without installation or install them globally for persistent access across your system.

What this guide helps you with

  • Run tools like ruff, black, or httpie without installing them
  • Install tools globally for persistent command-line access
  • List and manage installed tools
  • Update your shell PATH to use installed tools directly

How to use these commands

  • Use uvx for one-off commands — no installation needed
  • Use uv tool install for tools you use frequently
  • Run uv tool update-shell after installing tools to update your PATH
  • Use uv tool list to see what tools are installed
  • Use uv tool run to execute installed tools
