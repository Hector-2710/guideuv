Tools

Running and installing tools published to Python package indexes, e.g., ruff or black

Run tools on demand

  • uvx / uv tool run: Run a tool in a temporary environment
  • uvx ruff: The uvx command invokes a tool without installing it
  • uvx --from httpie http: The --from option can be used to invoke a command from a specific package, e.g., http which is provided by httpie

Install tools

  • uv tool install: Install a tool user-wide
  • uv tool uninstall: Uninstall a tool
  • uv tool list: List installed tools
  • uv tool update-shell: Update the shell to include tool executables

See the guide on tools to get started
