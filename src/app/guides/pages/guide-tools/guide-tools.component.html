📄 Guide

Tools

Running and installing tools published to Python package indexes, e.g., ruff or black.

▶

Run tools on demand

Use uvx or uv tool run to run a tool in a temporary environment without installing it.

Run uvx ruff The uvx command invokes a tool without installing it
Run uvx --from httpie http Invoke a command from a specific package
Run uv tool run ruff Run a tool in a temporary environment
📦

Install tools

Install tools user-wide for persistent access across your system.

Install uv tool install Install a tool user-wide
Remove uv tool uninstall Uninstall a tool
List uv tool list List installed tools
Setup uv tool update-shell Update the shell to include tool executables

See the guide on tools to get started.
