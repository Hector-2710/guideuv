Projects

uv simplifies Python project management by centralizing everything in the standard pyproject.toml file. Forget about manually setting up virtual environments or dealing with outdated requirements files; uv automatically keeps everything synchronized.

Create a new project

Initialize a new Python project with uv init. This creates a standard project structure.

$ uv init my-project
Project Structure 
├── .git/
├── .gitignore
├── .python-version
├── README.md
├── main.py
└── pyproject.toml

Project commands

Manage your Python project with these essential commands.

Add uv add Add a dependency to the project
Remove uv remove Remove a dependency from the project
Sync uv sync Sync project's dependencies with the environment
Run uv run Run a command in the project environment
Tree uv tree View the dependency tree for the project
Build uv build Build the project into distribution archives
Publish uv publish Publish the project to a package index
