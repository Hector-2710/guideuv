📄 Guide

Projects

uv simplifies Python project management by centralizing everything in the standard pyproject.toml file. Forget about manually setting up virtual environments or dealing with outdated requirements files; uv automatically keeps everything synchronized.

1. Initialize a new project

Creates the basic structure of a Python project with uv init. Automatically generates essential files: pyproject.toml, main.py, and Git configuration.

$ uv init
Example 
$ uv init my-project
Created project `my-project` at `/path/to/my-project`
$ cd my-project && ls -la
.git/  .gitignore  .python-version  README.md  main.py  pyproject.toml

2. Add dependencies

Installs and registers packages in your project with uv add. Automatically adds dependencies to pyproject.toml and installs them in the virtual environment.

$ uv add
Example 
$ uv add requests flask
Added 2 packages: requests (2.31.0), flask (3.0.0)
$ uv add pytest --dev
Added 1 package: pytest (7.4.0) (dev)

3. Remove dependencies

Uninstalls and removes packages from your project with uv remove. Cleans both the virtual environment and the references in pyproject.toml.

$ uv remove
Example 
$ uv remove requests
Removed 1 package: requests
$ uv remove pytest --dev
Removed 1 package: pytest

4. Sync environment

Synchronizes project dependencies with the virtual environment using uv sync. Ensures the environment exactly matches what's defined in pyproject.toml.

$ uv sync
Example 
$ uv sync
Resolved 12 packages in 2.3s
Installed 12 packages in 1.5s
$ uv sync --all-extras
Resolved 18 packages in 2.8s
Installed 18 packages in 2.1s

5. Run commands

Executes scripts or commands within the project virtual environment with uv run. Automatically activates the environment and runs the command without manual activation.

$ uv run
Example 
$ uv run python main.py
Hello, World!
$ uv run pytest
======================== test session starts =========================
collected 15 items
tests/test_main.py::test_hello PASSED                           [  6%]
...
======================== 15 passed in 0.32s ========================

6. View dependency tree

Shows the complete dependency tree with uv tree. Displays all direct and indirect dependencies, useful for resolving version conflicts.

$ uv tree

$ uv tree

7. Build package

Compiles and packages your project for distribution with uv build. Generates wheel and source files in the dist/ folder ready for publishing.

$ uv build
Example 
$ uv build
Building wheel for my-project (1.0.0)
  - Building: my_project/__init__.py
  - Building: my_project/main.py
  - Building: pyproject.toml
  - Adding: README.md
  - Adding: LICENSE
Finished building
  - my_project-1.0.0-py3-none-any.whl (12.3 KB)
  - my_project-1.0.0.tar.gz (8.7 KB)
$ ls dist/
my_project-1.0.0-py3-none-any.whl
my_project-1.0.0.tar.gz

8. Publish package

Publishes your package to a Python index (PyPI or other) with uv publish. Uploads the files generated by uv build to the configured repository.

$ uv publish
Example 
$ uv publish
Publishing my-project (1.0.0) to https://upload.pypi.org/legacy/
  - Uploading my_project-1.0.0-py3-none-any.whl
  - Uploading my_project-1.0.0.tar.gz
Successfully published my-project 1.0.0
$ uv publish --token pypi-***
Publishing my-project (1.0.0) to https://upload.pypi.org/legacy/
Successfully published my-project 1.0.0
