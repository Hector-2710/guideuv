📄 Guide

The pip interface

Manually managing environments and packages — intended to be used in legacy workflows or cases where the high-level commands do not provide enough control.

Create virtual environment

Create a new virtual environment. Replaces venv and virtualenv.

$ uv venv
Example 
$ uv venv
Created virtual environment at .venv
$ uv venv --python 3.12
Created virtual environment at .venv with Python 3.12.8
📂 Create uv venv Create virtual environment

Install packages

Install packages into the current environment. Replaces pip install.

$ uv pip install
Example 
$ uv pip install requests flask
Resolved 2 packages in 1.2s
Installed 2 packages: requests (2.31.0), flask (3.0.0)
$ uv pip install -r requirements.txt
Resolved 15 packages in 3.5s
Installed 15 packages
➕ Install uv pip install Install packages

Show package info

Show details about an installed package. Replaces pip show.

$ uv pip show
Example 
$ uv pip show requests
Name: requests
Version: 2.31.0
Summary: Python HTTP for Humans.
Home-page: https://requests.readthedocs.io
Author: Kenneth Reitz
License: Apache 2.0
Requires: certifi, charset-normalizer, idna, urllib3
🛈 Info uv pip show Show package details

📋 List uv pip list List installed packages

Freeze packages

List installed packages and their versions in a format suitable for requirements files.

$ uv pip freeze
Example 
$ uv pip freeze
certifi==2023.11.17
charset-normalizer==3.3.2
flask==3.0.0
idna==3.6
requests==2.31.0
urllib3==2.1.0
werkzeug==3.0.1
$ uv pip freeze > requirements.txt
Saved to requirements.txt
📄 Freeze uv pip freeze Export packages to requirements

Check packages

Check that the current environment has compatible packages and no conflicts.

$ uv pip check
Example 
$ uv pip check
No broken requirements found!
$ uv pip check
requests 2.31.0 requires charset-normalizer>=2,<3 but 3.3.2 is installed
✅ Check uv pip check Verify package compatibility

Uninstall packages

Uninstall packages from the current environment. Replaces pip uninstall.

$ uv pip uninstall
Example 
$ uv pip uninstall requests
Uninstalled 1 package: requests
$ uv pip uninstall flask werkzeug
Uninstalled 2 packages: flask, werkzeug
🗑 Remove uv pip uninstall Uninstall packages

Compile requirements

Compile requirements into a lockfile. Replaces pip-compile.

$ uv pip compile
Example 
$ uv pip compile requirements.in -o requirements.txt
Resolved 15 packages in 4.2s
Compiled 15 packages to requirements.txt
$ uv pip compile pyproject.toml -o lock.txt
Resolved 18 packages in 3.8s
Compiled 18 packages to lock.txt
📝 Compile uv pip compile Generate lockfile

Sync environment

Sync an environment with a lockfile. Replaces pip-sync.

$ uv pip sync
Example 
$ uv pip sync requirements.txt
Resolved 15 packages in 2.1s
Installed 15 packages
$ uv pip sync lock.txt
Resolved 18 packages in 1.8s
Installed 18 packages
🔄 Sync uv pip sync Sync with lockfile

Summary

This guide covers the low-level pip-like interface for uv. These commands give you fine-grained control over virtual environments and package management, useful for legacy workflows or when you need more control than the high-level commands provide.

What this guide helps you with

  • Create and manage virtual environments manually
  • Install, list, and uninstall packages in a specific environment
  • View package details and dependency trees
  • Generate lockfiles and sync environments from them
  • Check for package conflicts and compatibility issues

How to use these commands

  • Start with uv venv to create a virtual environment
  • Use uv pip install to add packages to that environment
  • Use uv pip compile to generate a lockfile from requirements
  • Use uv pip sync to ensure your environment matches the lockfile
  • Use uv pip check to verify there are no conflicts
