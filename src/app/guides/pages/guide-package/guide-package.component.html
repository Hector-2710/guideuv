📄 Guide

Package

uv supports building Python packages into source and binary distributions via uv build and uploading them to a registry with uv publish.

Build package

Build your Python project and create distribution artifacts in the dist/ directory.

$ uv build
Example 
$ uv build
Building wheel for my-package (1.0.0)
  - Building: my_package/__init__.py
  - Building: my_package/core.py
  - Building: pyproject.toml
  - Adding: README.md
  - Adding: LICENSE
Finished building
  - my_package-1.0.0-py3-none-any.whl (15.2 KB)
  - my_package-1.0.0.tar.gz (10.1 KB)
$ ls dist/
my_package-1.0.0-py3-none-any.whl
my_package-1.0.0.tar.gz

Publish package

Upload your built packages to a registry (PyPI by default or a custom index).

$ uv publish
Example 
$ uv publish
Publishing my-package (1.0.0) to https://upload.pypi.org/legacy/
  - Uploading my_package-1.0.0-py3-none-any.whl
  - Uploading my_package-1.0.0.tar.gz
Successfully published my-package 1.0.0
$ uv publish --token pypi-***
Publishing my-package (1.0.0) to https://upload.pypi.org/legacy/
Successfully published my-package 1.0.0

Update version

Update the version of your project in pyproject.toml.

$ uv version
Example 
$ uv version 1.0.0
Updated version from 0.1.0 to 1.0.0
$ uv version --bump patch
Updated version from 1.0.0 to 1.0.1
$ uv version --bump minor
Updated version from 1.0.1 to 1.1.0
